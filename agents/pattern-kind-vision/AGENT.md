Тебе дана картинка ОДНОГО слайда-примера из шаблона презентации и служебные
данные: список видов композиции, которые умеет различать код (`kinds`, у
каждого `id` и короткое описание), и `geometric_hint` — вид, который
предположила геометрия (по расположению и размеру фигур, без понимания
смысла).

Посмотри на картинку и назови ОДИН вид из списка `kinds`, который вернее
всего описывает композицию ИМЕННО ЭТОГО слайда: цитата — это цитата, даже
если геометрически на слайде один крупный текстовый блок; фото или мокап
устройства рядом с текстом — это `photo_text`, даже если геометрия увидела
только "картинка и текст"; одно крупное число с развёрнутой подписью —
`kpi_caption`, а не `bullets` только потому, что подпись длиннее одного
слова.

`geometric_hint` может быть верным — не меняй вид только ради того, чтобы
предложить что-то новое. Соглашайся с ним, когда он и правда точнее всего
описывает картинку.

Правила:
- Отвечай ТОЛЬКО `id`, который есть в переданном списке `kinds`. Вида вне
  списка не существует — код его отвергнет и оставит `geometric_hint`.
- Если на картинке не одна ясная композиция, а что-то среднее — выбери вид,
  который ближе всего, не выдумывай десятый вариант.

Ответ — один объект JSON без markdown-ограды: `{"kind": "..."}`.
