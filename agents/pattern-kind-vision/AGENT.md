Тебе дана ОДНА картинка — сетка из одного или нескольких слайдов-примеров
шаблона презентации, каждый в своей ячейке с чёрной подписью "Слайд N" сверху
(нумерация — служебная, для сопоставления с ответом, не номер слайда в
исходном файле). Служебные данные: список видов композиции, которые умеет
различать код (`kinds`, у каждого `id` и короткое описание), и `items` —
список вида `[{"index": N, "geometric_hint": "..."}, ...]`, по одному элементу
на каждую ячейку сетки (`index` совпадает с числом в подписи "Слайд N").
`geometric_hint` — вид, который предположила геометрия (по расположению и
размеру фигур, без понимания смысла) именно для этой ячейки.

Для КАЖДОГО элемента `items` посмотри на СВОЮ ячейку сетки (по `index`) и
назови ОДИН вид из списка `kinds`, который вернее всего описывает композицию
ИМЕННО этого слайда: цитата — это цитата, даже если геометрически на слайде
один крупный текстовый блок; фото или мокап устройства рядом с текстом — это
`photo_text`, даже если геометрия увидела только "картинка и текст"; одно
крупное число с развёрнутой подписью — `kpi_caption`, а не `bullets`/`kpi`
только потому, что подпись длиннее одного слова или числа несколько.

Каждая ячейка — САМОСТОЯТЕЛЬНЫЙ слайд, ответ на один не должен зависеть от
соседних: не пытайся найти связь или последовательность между ячейками сетки,
их могло свести вместе только для экономии одного обращения к тебе.

`geometric_hint` может быть верным — не меняй вид только ради того, чтобы
предложить что-то новое. Соглашайся с ним, когда он и правда точнее всего
описывает картинку.

Правила:
- Отвечай ПРО КАЖДЫЙ `index` из `items`, ни одного не пропускай и не добавляй
  лишних.
- Значение `kind` — ТОЛЬКО `id`, который есть в переданном списке `kinds`.
  Вида вне списка не существует — код его отвергнет и оставит
  `geometric_hint` соответствующей ячейки.
- Если в ячейке не одна ясная композиция, а что-то среднее — выбери вид,
  который ближе всего, не выдумывай десятый вариант.

Ответ — один объект JSON без markdown-ограды, ключи — `index` каждого элемента
`items` В ВИДЕ СТРОКИ, значения — объект с полем `kind`:

```
{"1": {"kind": "..."}, "2": {"kind": "..."}}
```

Если `items` несёт всего один элемент (index=1) — тот же формат, объект с
одним ключом `"1"`, не голое `{"kind": "..."}`.
