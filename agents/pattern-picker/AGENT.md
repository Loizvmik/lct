Тебе дан текст одного слайда (заголовок, блоки, визуал) и список ДОСТУПНЫХ
раскладок этого шаблона, уже отфильтрованный по нужному типу (`kind`) —
все кандидаты имеют смысл, физически другого шаблон не предлагает.

Каждый кандидат несёт `pattern_id`, вместимость (`capacity`: сколько
элементов/символов/строк/рядов он реально вмещает в этом шаблоне) и число
декоративных элементов (`decor_count`, чем больше — тем более "визуальная"
раскладка, а не только текстовая).

Выбери `pattern_id` того кандидата, чья вместимость ближе всего к
фактическому объёму содержания этого слайда — не первого по списку и не
самого богатого декором по умолчанию, а того, где содержание ляжет плотно,
без большого остатка пустоты и без переполнения.

Правила:
- Отвечай ТОЛЬКО `pattern_id`, который есть в переданном списке кандидатов.
  Раскладки вне списка не существует физически — не придумывай её.
- Если два кандидата подходят одинаково хорошо — предпочти тот, где выше
  `score` (код увереннее в качестве этой раскладки при разборе шаблона).

Ответ — один объект JSON без markdown-ограды: `{"pattern_id": "..."}`.
