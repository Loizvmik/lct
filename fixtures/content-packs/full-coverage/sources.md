## Сравнение: ручная маршрутизация и автоматическая

| Критерий | Ручная | Автоматическая |
|---|---|---|
| Кто назначает согласующего | автор заявки | правило по типу и сумме |
| Подмена отсутствующего | вручную, по звонку | из кадровой системы |
| Время назначения | до 4 часов | 2 секунды |
| Ошибки назначения | 39% заявок | 4% заявок |

## Как устроено правило маршрутизации

Правило описывается на Python и хранится в репозитории платформы. Пример
правила для закупок:

```python
def route(request: Request) -> list[Approver]:
    if request.kind == "purchase" and request.amount > 5_000_000:
        return [head_of(request.unit), cfo()]
    if request.kind == "purchase":
        return [head_of(request.unit)]
    return [line_manager(request.author)]
```

Правило проверяется тестами при каждом изменении: 214 автотестов, прогон
40 секунд.

## Портал

Скриншот портала (portal-screenshot.png): очередь согласования с кнопкой
«Согласовать», список заявок с числом дней в очереди. Портал открывается из
корпоративного мессенджера без отдельного входа.

## Как это работает: шаги

1. Автор создаёт заявку в портале, форма подсказывает обязательные поля.
2. Правило маршрутизации назначает согласующих за 2 секунды.
3. Согласующий получает карточку в мессенджере и решает одним нажатием.
4. При отсутствии согласующего система берёт замену из кадровой системы.
5. Исполнитель получает задачу с полным пакетом документов.
