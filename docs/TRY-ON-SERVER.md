# Как проверить «Донор» на сервере

Адрес: **http://72.56.4.12:8090**

На сервере нет своего ключа модели. Чтобы генерировать презентации, нужен
ваш ключ Yandex AI Studio: он хранится только в вашем браузере и уходит на
сервер вместе с запросами. Генерация тратит квоту вашего каталога: около
30 вызовов модели на презентацию.

## 1. Получить ключ и ID каталога (5 минут)

1. Откройте [консоль Yandex Cloud](https://console.yandex.cloud) и
   выберите каталог (или создайте новый).
2. ID каталога указан на странице каталога, строка вида `b1g...`.
   Скопируйте его.
3. В каталоге откройте «Сервисные аккаунты» → «Создать сервисный аккаунт»,
   добавьте роль **`ai.languageModels.user`**.
4. Откройте созданный аккаунт → «Создать новый ключ» → «Создать API-ключ».
   Скопируйте ключ: он показывается один раз.

## 2. Вставить ключ в приложение

1. Откройте http://72.56.4.12:8090.
2. Нажмите значок настроек в правом верхнем углу.
3. В разделе **«Yandex AI Studio»** вставьте API-ключ и ID каталога.
   Там же видно, какая модель используется: Qwen3.6-35B-A3B (35B
   параметров, 3B активных, Apache 2.0).
4. Нажмите **«Проверить»**. Должно появиться «Ключ работает».
5. Закройте настройки. Кнопка «Забыть» удаляет ключ из браузера.

## 3. Создать презентации

1. **Загрузите шаблон** `.pptx` (до 100 МБ): перетащите файл на главную
   страницу. Первый разбор незнакомого шаблона идёт 3–7 минут, не
   закрывайте страницу. Шаблоны датасета (VK Tech, VK Education,
   VK WorkSpace) сервер уже разобрал, они загружаются за секунду.
2. Посмотрите сводку по шаблону: цвета, шрифты, найденные макеты.
   Нажмите **«Перейти к заданию»**.
3. **Опишите задачу:**
   - «Название презентации», можно оставить пустым;
   - «Задача презентации», обязательно: цель, аудитория, тон;
   - «Исходные материалы»: факты, цифры, таблицы, фрагменты кода;
   - «Фотографии», по желанию: до 10 файлов jpg/png, у каждого подпись.
   Кнопки «Пример: заявки» и «Пример: учебная платформа» заполняют форму
   готовым текстом, если нужно быстро попробовать.
4. Стиль **«Все три стиля»**, нажмите **«Создать три варианта»**. Три
   презентации собираются параллельно, обычно за 40–70 секунд.
5. На странице результата три карточки: **Плотный**, **Воздушный**,
   **Визуальный**. «Проверить вариант» открывает слайды и замечания
   проверки. Скачать можно в PDF, PowerPoint или открыть веб-версию.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| «Не указан ключ Yandex AI Studio» | вставьте ключ и ID каталога в «Настройках» (шаг 2) |
| «Ключ Yandex AI Studio не принят: Неверный API-ключ» | ключ скопирован не целиком или удалён; создайте новый |
| «…Каталог не найден или нет доступа к модели» | проверьте ID каталога и роль `ai.languageModels.user` у сервисного аккаунта |
| «Нет связи с Yandex Cloud» | повторите через минуту |
| «Готово с предупреждениями» у карточки | это нормально: сервис перечисляет, что учёл не полностью (например, какое фото не встало и почему) |
| страница долго показывает этапы | обновите её: задания продолжаются на сервере |
