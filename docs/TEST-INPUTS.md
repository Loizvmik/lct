# Готовые входные данные для ручных прогонов

Чтобы не придумывать бриф каждый раз. В интерфейсе на экране задания две
кнопки: «Пример: заявки» и «Пример: учебная платформа», они вставляют то же
самое. Ниже те же тексты для копирования и пути к фотографиям.

Шаблоны для загрузки: `dataset/templates/*.pptx` (VK Tech, VK Education,
VK WorkSpace, ЛЦТ2026). Кэш разбора для всех четырёх обычно уже прогрет.

## 1. Заявки (`fixtures/content-packs/queue-latency`)

Название: `Сокращение времени согласования заявок`

Слайдов: 12

Бриф:

```
Просим комитет согласовать запуск автоматической маршрутизации заявок на
внутренней платформе. Надо показать, где уходит время, что дал пилот и что
нужно для раскатки на всю компанию.

Тон деловой, без превосходных степеней. Аудитория знает предметную область,
объяснять базовые вещи не надо.
```

Источники: содержимое `fixtures/content-packs/queue-latency/sources.md`
(таблица замера процесса, причины ожидания, результаты пилота, план
раскатки, бюджет 2,4 млн ₽).

Фотографии: `fixtures/content-packs/queue-latency/photos/approver-laptop-review.jpg`,
`fixtures/content-packs/queue-latency/photos/team-standup-tablet.jpg`.

## 2. Учебная платформа (`fixtures/content-packs/edu-platform`)

Название: `Итоги учебной платформы за 2026 год`

Слайдов: 12

Бриф:

```
Годовой отчёт по образовательной платформе. Показать охват, качество обучения,
экономику и план на 2027 год. Совет интересуют доведение до конца и стоимость
одного выпускника, а не количество запущенных курсов.
```

Источники: содержимое `fixtures/content-packs/edu-platform/sources.md`
(охват по кварталам, изменения четвёртого квартала, качество, экономика
2025/2026, план 2027, ограничения данных).

Фотографии: `fixtures/content-packs/edu-platform/photos/mentor-tablet-demo.jpg`,
`fixtures/content-packs/edu-platform/photos/students-project-review.jpg`.

## Через командную строку

```
deckforge generate "dataset/templates/Шаблон презентации VK Education.pptx" fixtures/content-packs/queue-latency -o out/
deckforge generate "dataset/templates/VK Tech шаблон.pptx" fixtures/content-packs/edu-platform -o out/ --style visual
```

Ключ модели берётся из `.env`. Один стиль укладывается в 300 с; три стиля
сразу делят одну квоту модели, для замера времени запускайте один.

## Что смотреть после прогона

- в интерфейсе: карточка задания (время, режим, оценки модели, верность
  шаблону, как собраны слайды, что требует другого текста), затем
  «Проверить вариант»;
- в файлах: `artifacts/api/decks/<job>/<style>/deck.pptx`, `deck.json`
  (план колоды), `preview/*.png`, `deck.html` (отчёт);
- быстрый обзор сборки: `scripts/inspect_deck.py <deck.pptx>` печатает, каким
  путём собран каждый слайд (клон, запасная раскладка, с нуля).
